Kepada Yth. Tim Keamanan Wibuku,

Perkenalkan, saya Afif, peneliti keamanan independen dari Indonesia. 
Saya melakukan riset terhadap platform wibuku.app dan menemukan 
beberapa kerentanan keamanan yang perlu saya laporkan secara bertanggung jawab.

TEMUAN:

1. CRITICAL — Mass Account Takeover via email-only /login
   Endpoint POST https://premium.wibuku.app/login menerima request 
   {"email": "<user_email>"} dan langsung mengembalikan session token 
   tanpa verifikasi password, OTP, atau metode autentikasi lainnya.
   
   Dampak: Siapapun yang mengetahui email user terdaftar dapat mengambil 
   alih akun, termasuk fitur premium dan data pribadi user.

2. HIGH — CORS Misconfiguration di airmanager.wibuku.app
   Header Access-Control-Allow-Origin: * dengan semua method HTTP 
   diizinkan (GET/POST/PUT/DELETE/PATCH). Memungkinkan CSRF + data 
   exfiltration.

3. MEDIUM — Data pribadi user terekspos di Wayback Machine
   URL https://premium.wibuku.app/?session=<token> pernah terindeks oleh 
   Wayback Machine dan berisi PII user (id, username, email, foto profil).

TIMELINE:
- Saya tidak menyimpan, mendownload, atau menggunakan data user 
  untuk kepentingan apapun.
- Saya menghentikan pengujian setelah konfirmasi漏洞 tanpa eksploitasi 
  lebih lanjut.
- Saya siap memberikan detail teknis lengkap dan proof of concept 
  setelah tim Wibuku memberi saya kontak yang tepat.

Saya berharap laporan ini dapat membantu Wibuku meningkatkan keamanan 
platform. Mohon informasinya jika ada program bug bounty atau security 
acknowledgment yang sesuai.
